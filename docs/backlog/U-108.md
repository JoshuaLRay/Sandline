Design: [U-107 construction specification](../design/maps/qalat-road.md), especially §14.

## Scope

First focused prerequisite: optional vertical bounds for world/encounter/mission/
script areas, shared height-aware containment, optional authored enemy spawn-zone
floor, and correct server spawn projection/occupancy across stacked floors.
Legacy 2D content retains its current semantics. Missing height must not satisfy
a height-bounded trigger. Invalid authored floor must fail instead of silently
placing enemies on a roof or leaving a mission empty.

This does not yet add six squad starts, fixed per-member sockets, 3D patrols,
vehicle paths, nav/cover/order changes, supplies, save revisions or map geometry.
U-109–U-119 split those remaining implementation packages explicitly.
