Epic: Map implementation. Status, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).

## Problem / outcome

`Session.applyCaptured` currently holds squad prisoners at saved coordinates.
Mission data has no authored current-map holding sockets for these slots. The
separate seventh escort POW cannot substitute for up to five carried prisoners.
An incompatible-map restart must retain the original pool without transplanting
coordinates or inventing locations. Mission 2's design §13/§17 N3 describes a
future holding-socket capability, not an implemented contract.

both campaign and replay starts, preserve original inventory/pool membership,
and enable U-143's currently blocked restart action. Never move saved prisoner
coordinates into changed geometry or replace them with squad spawn guesses.
