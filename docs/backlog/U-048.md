# U-048 — Equipment foundation: per-character slot 5, Brennan's launcher, droppable equipment

Epic: **Controls**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: [U-044](U-044.md), owner direction 2026-09-29; design decided 2026-09-30 (below). The items themselves are U-054 to U-058.

## Problem / outcome

Slot 5 (equipment) differs per character, and the code cannot say so yet: the launcher is a pouch item that both Preach and Brennan carry, the wire's item fields are nearly full, and equipment cannot be dropped. This card is the foundation the five equipment items stand on.

## Owner decisions (2026-09-29 and 2026-09-30)

| Character | Slot 5 | Card |
|---|---|---|
| Holloway (Support) | C4 x2 | U-054 |
| Brennan (LMG) | Rocket launcher x2 | this card |
| Preach (lead) | Concussion grenade **x4** | U-056 |
| Ortiz (scoped AR, team 2 lead) | Smoke grenade x2 *(proposal, not objected to)* | U-058 |
| Marsh (left-handed sniper) | Claymore x1 | U-055 |
| Vance (sniper) | Motion sensor x1 | U-057 |

- Equipment is droppable: G drops the item in hand, E picks it up (the gun lifecycle of U-029).
- Slot 5 is a "force a swap to use" slot like the rest (U-045): draw with key 5, then the click controls (U-046).

## Scope

1. **Data:** `classes.json` gains a per-character `equipment` (item id to count), replacing the launcher in `pouch`. Preach loses his rocket. Until an item's card lands, that character's slot 5 is empty ("no equipment").
2. **Wire:** more than four item kinds no longer fit. Widen the projectile index and the Weapon component's "in hand" field, and give the Equip item code more bits (today 10 guns + 2 projectiles + the kit sit under `RELOAD_ITEM` 15). Protocol bump.
3. **Brennan's launcher:** slot 5, 2 rockets, single shot, otherwise as the rocket is today.
4. **Droppable equipment:** G drops the equipment in hand as a world pickup carrying its item and count (the pickup entity gains an item kind beside its weapon index); E picks it up if the character's slot accepts it (a character takes only its own kind of equipment, or any, to be decided in review; proposal: any character may carry any item, one kind at a time).
5. **HUD:** the slot-5 row shows the character's item, count and selection.

## Acceptance criteria

- [x] `equipment` is character data; Preach no longer carries a rocket; Brennan carries 2 rockets in slot 5 and no other character can draw a rocket.
- [x] The wire carries at least six item kinds with room to grow; an old-protocol client is refused by version.
- [x] G drops the equipment in hand; E picks it up with its count; nothing is duplicated or lost (host-authoritative, like U-029).
- [x] Key 5 draws the character's item, or says "no equipment" for an empty slot.

## Verification

Shared schema/protocol tests, server tests for the drop and pickup, a hosted-session test for each affected path, `pnpm verify` and the CI jobs.
