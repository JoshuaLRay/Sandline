# U-019 — Specify the six named characters and their skills

Epic: **Squad**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: [owner feedback, 2026-09-26](2026-09-26-feedback.md), plus any legacy bug named below.

## Problem / outcome

The owner specifies six unique named characters: two snipers, one LMG, one AR, one scoped AR, and a faster support carrying SMG + shotgun with no ADS or FPS. The slot-0 leader is named Preach. On 2026-09-29 the owner accepted the other names and the support details, and deferred skills to a later version.

## Scope

Maintain docs/design/squad-roster.md with six original fictional identities, fixed role/loadout assignments and one distinct, bounded skill proposal per character. Record Preach as the approved slot-0 leader name, label the other display names and skills as proposals, and separate approved requirements from open choices. Propose an ADR addendum reconciling the legacy two-class slice and ADR-001/020 with the new roster; the user already authorizes the six-role direction.
