# U-100 — Let the commander adjust squad spread

Epic: **Squad command**. Status, priority and dependencies live in [BACKLOG.md](../../BACKLOG.md).
Source: owner, 2026-10-03: control “the tightness of the spread of the group.”

## Problem / outcome

Formation offsets and their stationary/sprint scaling are fixed in
`squad.json`. The player needs an in-game control over how closely followers
travel together. Tight formations must retain U-099's physical separation.

## Scope

One focused PR after U-099. Add **Tight / Standard / Wide** group presets;
proposed offset scales are **0.65 / 1 / 1.5**, stored as validated tuning data.
Standard retains the current formation footprint. Apply the choice to bots
under the issuing player's command, respecting current command ownership.
Expose the setting in a touch-accessible squad command UI and synchronize the
authoritative selection to all clients, including late joiners.

Scale right/back offsets and their formation bands consistently. Reserve
distinct reachable places when navmesh projection squeezes the formation.
In bottlenecks queue or fall into file rather than stacking characters.
Movement and hold orders addressed to several bots need distinct destinations;
preserve explicit single-character orders and revive/interaction reach.
Settings belong to the session: retain through possession and checkpoint retry,
initialize Standard for a new session. No aggression change in this task.

## Acceptance criteria

- [x] Switching the preset visibly changes follow spacing while stationary,
  walking, sprinting and turning; Standard preserves the existing default.
- [x] Tight never permits occupied or coincident character destinations.
- [x] Wide respects navigation, cover and valid terrain; bottlenecks remain
  passable without follower starvation.
- [x] Group move/hold destinations remain distinct; healing, revival and
  objective interactions remain within their required reach.
- [x] Only authorized bots change; selection replicates, survives reconnect,
  possession and retry, and resets for a new session.
- [x] The control is usable on desktop and touch in both phone orientations.

## Handoff / evidence

Implemented validated Tight / Standard / Wide scales 0.65 / 1 / 1.5,
formation-place reservation and scaled group-order destinations. The physical
minimum from U-099 still applies. The Squad panel exposes group spread for
commanded bots; the server checks ownership and publishes authoritative settings
to all clients, including late joiners. Presets live on the Session and persist
when its character is possessed or its checkpoint is restored.
