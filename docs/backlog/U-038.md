# U-038 — Mobile zoom-out limit: 6x portrait, 3x landscape

Epic: Mobile. Status, priority, dependencies and branch/PR live in BACKLOG.md.
Source: 2026-09-29, owner playtest feedback on a phone: "Changing to landscape on mobile makes the game think I am on desktop. This should not be the case. The zoom out cam should be up to 6x (double what it is now) when in portrait mode on mobile. 3x (as now) for landscape mode on mobile. Mobile players should never see cross hairs."

## Problem / outcome

Currently the mobile pinch zoom-out spans 3x (camera distance 3 to 9 in `main.ts`).
Desired: up to 6x (distance 3 to 18) in portrait; unchanged 3x (3 to 9) in landscape.
Behaviour on rotation while zoomed (clamp vs preserve): UNKNOWN; proposal: clamp to the new orientation's limit.

## Scope

One PR: orientation-dependent max distance for the mobile third-person/spectator
camera. Depends on U-037 so mobile detection is reliable in landscape. Check camera
collision and far-plane/fog at 18 units.

## Start here

`mobileCameraDistance` and the pinch handler near `packages/client/src/main.ts:1770-1800`, use at ~2840; `camera/cameraSolve.ts`.

## Acceptance criteria

- [ ] Portrait mobile can pinch out to 6x the minimum distance; landscape stays at 3x.
- [ ] Rotating clamps the current zoom into the new limit without a jump-cut glitch.
- [ ] Limits live in a tested pure function; desktop camera unchanged.

## Verification

`pnpm verify` plus a unit test for the limit; visual check in portrait/landscape emulation.

## Handoff / evidence

Branch `task/U-038-mobile-zoom`, built on the U-037 merge in #181.
- `ui/mobileDevice.ts`: `mobileCameraMax(portrait)` (18 portrait, 9 landscape) and `clampMobileCameraDistance`, unit-tested. `main.ts` uses them in the pinch handler and re-clamps every frame, so rotating while zoomed out snaps the distance to the new limit (a snap, not an animated ease).
- Portrait = `innerHeight > innerWidth`. Desktop distance (3) unchanged.
- Checked: `pnpm typecheck`, `pnpm lint`, targeted vitest pass; full `pnpm verify` runs in CI on the PR.
- Owner accepted the phone zoom review disposition on 2026-10-09: pinch range, rotation while zoomed and the 18-unit fog/geometry presentation (see below).
