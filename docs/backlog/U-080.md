# U-080 — Realistic character models: a more grounded look

Epic: **Art**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: owner decision D1, 2026-10-01 ([design doc](../design/CAMPAIGN.md)).

## Problem / outcome

The owner finds the characters too cartoonish, even for PS2 standards, comparing them with *Conflict: Desert Storm*: ours are scrawny and look 'drawn'. The campaign is now grounded, post-9/11 Afghanistan.

## Scope

**Decided 2026-10-01 (owner's defaults):** improve the procedural/code-built pipeline (no authored-model import, so no new runtime dependency or ADR); re-proportion and re-texture the current rig; the reference is *Conflict: Desert Storm* as the owner described it. No reference images have been supplied yet, so the first pass is from that description and goes to the owner as screenshots for review; the owner can add images at any point. The characters are procedural/code-built humanoids (`packages/client/src/character`, `tools/src/art/characters`). Proposed first step: a short art-direction pass, then a re-proportion of the rig (heavier torso, shoulders and limbs, equipment volume, gear and uniform detail, flatter, less saturated palettes and texture) and a texture pass, judged against the owner's reference. Decisions needed: (1) the visual reference set; (2) whether to improve the procedural pipeline or commission/import authored models (a runtime dependency or asset format needs an ADR); (3) the polygon and texture budget for a six-plus-enemies scene. Enemy variants (Taliban/al-Qaeda dress) and the POW are part of it. No change to hitboxes or gameplay.
