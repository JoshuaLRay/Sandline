Implemented top-level, six-slot `squadStarts` for worlds and levels. Authoring
rejects invalid counts, non-finite/out-of-bounds positions, unsupported feet,
standing obstructions and overlapping slots. Session initialization, full
restart, retry without a checkpoint, ordinary respawn and missing checkpoint
slots use the same authored points. Checkpoints retain their saved positions;
joining still possesses the existing slot. Full authored restart faces north.

Vehicle scripts and encounter paths carry optional y. Authored 3D routes check
supported spawn/body placement and hull/turret clearance, including intermediate
segments, while runtime driving/turning checks support and obstacles. Soldiers
on another storey do not block the tank. The supported y survives standing,
driving, stopping, withdrawal, hitboxes, turret/muzzle/shell origins, snapshot
replication, checkpoint retry and durable JSON reload. Authored height is carried explicitly so a legacy navmesh offset (about 5 cm)
never opts a 2D route into height checks. Authored vehicle feet retain their
specified floor despite that nav offset. Legacy 2D path validation and steering
remain intact; old checkpoints without path/origin y still load.

Authoring/reproduction details are in [COMMANDS.md](../COMMANDS.md#authored-squad-starts-and-vehicle-height-u-110).
No map or generator inputs changed, so committed nav, cover and assets need no
regeneration. The replacement Mission 1 insertion/road belongs to U-114; this
capability PR does not claim the replacement map or an owner gameplay verdict.
