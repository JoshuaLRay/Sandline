# U-143 — Quarantine incompatible restores and provide safe host choices

Epic: Map implementation. Status, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).
Source: pre-claim split of [U-136](U-136.md), 2026-10-07 source inspection.

## Scope

Refuse missing/unknown or mismatched checkpoint revisions before saved positions,
events, spawners, inventory or prisoners enter the current simulation. Stop
gameplay/input and timers through ready-up, reconnect and host changes. Use a
validated protocol and desktop/mobile choice model to show exactly: “This mission
map has changed. Restart the mission to continue.” Only the host may restart or
select a mission allowed by the existing campaign rules.

Restart from current authored squad starts and the original mission-start
inventory; legacy saves explicitly use pre-mission campaign carry-over/class
inventory, never spent checkpoint stock. Preserve progress, XP/ranks, the other
prisoner pool and unrelated checkpoints. Keep the original refused save intact
until an explicit choice. Mission select preserves both pools and that checkpoint.

When the original active pool has prisoners, disable restart with an explicit
placement-unavailable explanation; preserve the pool without installing its old
coordinates. [U-144](U-144.md) owns authored carried-prisoner placement and enabling
those restarts. This leaf does not close U-136/U-113 or authorize map activation.
