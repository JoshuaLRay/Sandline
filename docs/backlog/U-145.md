# U-145 — Use supply caches through approved mobile controls

Epic: Map implementation. Status, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).
Source: U-134/U-112 mobile-use acceptance; split before claiming U-134 on 2026-10-07.

## Problem / outcome

U-134 requires mobile cache choice and use, but the
[approved mobile design](../design/mobile-spectator-commander.md) lets mobile
participants watch and command bots. U-133 rejects `SupplySelect` from spectators
and requires held soldier interaction input. A touch button alone cannot use a
cache in the production mobile path.

## Scope / blocker

Owner must choose how cache use fits the existing spectator/commander scope:
commander resupply with host-validated bot authority, or explicit supply-only
temporary possession with no walking, aiming or firing. Do not silently add
mobile TPS controls, fake a successful host use, or allow spectators to resupply
another human. Split protocol/AI/UI work into linked leaves before claiming if
the selected design exceeds one focused PR.

## Start here

`docs/adr/002-v1-scope-exclusions.md`; `docs/design/mobile-spectator-commander.md`;
`packages/client/src/main.ts` mobile spectator/tick path;
`packages/server/src/session/Session.ts` supply eligibility and selection;
`packages/client/src/ui/supplyChoice.ts` (U-134 presentation).

## Acceptance and verification

- Mobile chooses exactly one compatible item, starts and interrupts host use
  using the approved control design, and sees authoritative stock/progress.
- Full/incompatible/depleted choices consume no time/stock. Contention, changed
  permissions, human targets, focus loss, menu entry and reconnect remain safe.
- Reproducible browser and real Session coverage, `pnpm verify`, client build,
  applicable budgets/generators and all four latest-head CI jobs pass.
- Owner physical-phone presentation/play review is separately recorded.

## Handoff

Not claimed. Depends on U-134 and the explicit mobile control decision above.
U-134 supplies read-only mobile presentation; it does not fulfill this use gate.
