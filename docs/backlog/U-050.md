# U-050 — The support runs 10% faster

Epic: **Squad**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: [U-021](U-021.md) follow-up, owner decisions 2026-09-29 (D-4 in the roster doc).

## Problem / outcome

Owner decision (2026-09-29, D-4): the support (Holloway, slot 2) has +10% speed, as one configurable number in the character's data.

## Scope

A per-character `speedScale` (support 1.1, others 1.0) applied to walk and sprint speed in `stepCharacter`, identically on the server, in client prediction and in reconciliation, so it does not read as a correction. Shared movement changes need parity tests (numeric bounds, ADR-016 and `packages/shared/CLAUDE.md`). Applies to bots as well.

## Start here

`packages/shared/src/sim/CharacterController.ts` (speeds), `packages/shared/src/net/prediction.ts`, `packages/shared/src/data/classes.json`, `packages/server/src/session/Session.ts` (`stepCharacter` calls), `packages/client/src/net/NetClient.ts` (predictor input).

## Acceptance criteria

- [x] The support's walk and sprint are 10% faster than anyone else's, from one data value.
- [x] Server, prediction and replay agree (no rubber-banding), with parity tests.
- [x] Bots move with the same scale.

## Verification

Shared and server tests, then `pnpm verify` and the CI jobs.

## Handoff / evidence

Implemented on `task/U-050-support-speed`; awaiting review. Feel is a playtest judgement; no owner verdict is claimed.

**What changed.** `classes.json` gains `speedScale` (default 1, bounded 0.5 to 2; `holloway` 1.1). `MoveInput` gains an optional `speedScale`, a multiple on walking and sprinting speed in `stepCharacter`. It is not on the wire: the host sets it from the soldier's character before every step (humans, catch-up steps and bots alike), and the page sets it from its own character on the input it predicts, so prediction, replay and reconciliation step the same input and a forged client cannot change it. Crouch and prone are not scaled (proposal: the card says walk and sprint).

**Evidence.** `CharacterController.test.ts` (walk and sprint scaled by exactly 1.1; crouch, prone and downed unchanged; default identical), `prediction.test.ts` (predict + replay with the multiple reconciles with no error against the host's run), `packages/client/src/weapons/speedScale.test.ts` (a hosted support covers 1.10 times Preach's ground, walking and sprinting), `classes.test.ts`.
