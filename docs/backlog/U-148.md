## Implementation and engineering evidence — 2026-10-09

Fresh main was `d9a4c7b`, including verified U-147 merge #320; no PR was open.
U-148 was the first eligible READY leaf, with U-146/U-147 DONE. The existing split
keeps this PR focused on phone controls and their confirmed-state adapter; no
protocol, cache transfer, navigation, generated-source or production-map changes.

**Supplies** opens a scrollable panel for one explicit commanded bot, cache and
item. It uses that recipient's current confirmed snapshot inventory and class
capacity, including the issuer's own spectator-driven bot. Class/fireteam reach,
ownership, alive/captured state and human control constrain recipients; watching
an active human never enables that human. Stock remains observable with no valid
recipient. Missing snapshots disable collection immediately, without waiting for
remote-render interpolation expiry. Rejoin clears confirmed recipient state;
older packets cannot roll it back.

Requests and cancellations use the merged reliable commander contract. Collection
progress and stock come only from the host. Zero percent says **Host accepted ·
waiting to collect**, because the wire does not distinguish travel from a new
collection. Completion/cancellation says **Host ended collection** without
inventing a transfer verdict. An unconfirmed request has a five-second timeout
that sends cancellation; accepted travel has no local timer. Duplicate selections
and repeated dismissal do not repeat the same request/cancellation. Recipient,
cache, authority, roster/class, focus/visibility, menu, restore, mission and
connection changes discard stale choices safely. Opening Supplies closes squad
menus and disarms order placement; another command-control gesture dismisses it.
