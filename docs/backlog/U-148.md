# U-148 — Mobile commander cache choice, cancellation and authoritative progress

Epic: Map implementation. Status, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).
Source: focused phone-interface leaf of [U-145](U-145.md), split on 2026-10-08.

## Scope

Use U-146/U-147 to select one eligible commanded bot and exactly one compatible
supply type, request collection and cancel it from the spectator/commander phone
interface. Use that recipient's confirmed inventory/capacity and host stock/
progress; retain no local transfer prediction. Watching an active human grants
no command authority. Manual mobile movement/aiming/firing remain excluded.

## Acceptance and verification

- [ ] Recipient/type choice, authoritative progress/stock and unavailable/empty
  states work in the actual mobile path without conflicting camera/order controls.
- [ ] Full/incompatible/depleted choices, ownership/roster change, focus loss,
  menu entry and reconnect fail/cancel safely without duplicate stock.
- [ ] Reproducible real Session/browser evidence covers contention, partial
  transfers, portrait/landscape layout, scrolling and safe-area fit.
- [ ] `pnpm verify`, client build, applicable budgets/generators and all four
  latest-head CI jobs pass; owner physical-phone presentation/play review is
  separately recorded and remains pending until supplied for this new use UI.
