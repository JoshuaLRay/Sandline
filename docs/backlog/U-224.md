# U-224 — Place carried squad prisoners in authored current-map holdings

Epic: Map implementation. Pillar: P5/P6. Size: L.
Human verdict: integrated replacement mission review in U-119.
Status, priority, dependencies and branch/PR live in BACKLOG.md.
Source: owner request to finish Qalat changes, 2026-10-17; prerequisite split of U-144.

## Problem / outcome

The replacement cell has physical capacity for five carried squad prisoners plus
the separate POW, but mission data cannot describe the carried holdings. Safe
incompatible-save restart therefore refuses every nonempty original prisoner pool.

## Scope

Add validated mission holdings, ordered by authoring. Map ascending captured squad
slot indices to that order for a new mission or an explicit incompatible-map
restart. Preserve the original pool, start inventory, XP and other run's pool.
Same-revision saves/retries retain their exact saved coordinates. Missing or
insufficient holdings retain the restore gate. Validate support, standing clearance,
bounds and mutual body separation before initializing a Session.

This is the technical placement/lifecycle contract. U-144 retains production
authoring and accessible rescue integration with U-117; U-178 retains forced-return
routing. No candidate coordinates enter the older active map. The approved new
cell's five positions will be authored with replacement activation, avoiding a
circular dependency between new-map placements and U-117 activation.
