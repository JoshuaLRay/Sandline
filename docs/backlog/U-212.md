# U-212 — Stealth tuning and verification

Epic: Stealth and enemy awareness ([U-204](U-204.md)). Pillar: P4.
Size: M. Human verdict: **this card** (batched for the epic).
Status, priority, dependencies and branch/PR live in [BACKLOG.md](../../BACKLOG.md).
Source: owner, 2026-10-16 — "Players should be able to use stealth to gain advantages, but missions must remain achievable after combat begins."

## Problem / outcome

Tune awareness numbers and verify, headless and in the owner's playtest, that
stealth pays (fewer simultaneous alerts, first shots on unaware targets), that
loud play still completes missions, and that the indicators are readable and
honest.

## Scope

- Headless: run each mission "quiet" (squad crouched, hold fire until
  detected) and "loud"; report detections, alarms, completion; loud completion
  must not fall below the pre-epic baseline.
- Owner playtest run sheet: desktop and phone indicator readability; whether
  enemies feel omniscient; whether stealth feels worth it.

## Read first

- U-205–U-211 handoffs; [STEALTH-AWARENESS.md](../design/STEALTH-AWARENESS.md)

## Acceptance criteria

- [ ] Quiet runs raise fewer alarms and alerts than loud runs on every mission (simulation).
- [ ] Loud completion not below the baseline recorded before U-205.
- [ ] Owner playtest verdict recorded (never invented).

## Verification

Simulation report in the card; owner playtest.

Not started.
