# U-136 — Refuse incompatible restores and offer restart or mission select

Epic: Map implementation. Status, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).
Source: implementation leaf of [U-113](U-113.md), Mission 1 specification §14.

## Scope

Use U-135's revision and original mission-start save data to gate restore before
old coordinates, prisoners, events or spawner state enter current geometry.
Missing/unknown and mismatched revisions require an explicit host decision;
never silently relocate, discard or relabel a checkpoint. Keep gameplay/input
and timers stopped while waiting, including ready-up, reconnect and host change.
Offer the exact message: “This mission map has changed. Restart the mission to
continue.” Provide restart or mission select on desktop/mobile through a
validated protocol contract and the existing campaign choice rules.

Restart uses authored current starts and the original mission-start inventory;
preserve completed missions, XP/ranks, both prisoner pools and unrelated saved
checkpoints. Handle legacy saves with no start snapshot explicitly, using the
existing pre-mission carry-over/class inventory without inventing spent stock.
Do not transplant saved prisoner coordinates into changed geometry; retain the
pool and use the current authored prisoner placement/lifecycle. Split further
before claiming if this requires an unresolved placement/product decision.

## Acceptance and verification

- Actual Session tests cover mismatched and missing revisions, no old-world
  initialization, no input/timer progress, host-only decisions, ready-up,
  reconnect and repeated restart; same revision restores full 3D world, pending
  timers, one-shot flags and inventory without replenishment.
- Protocol round-trips, headless client integration and desktop/mobile choice
  models cover the required message and usable restart/select actions.
- Restart/select preserves original inventory, campaign progress and prisoner
  pools; legacy handling and unrelated mission/run checkpoints are covered.
- Focused regressions, `pnpm verify`, applicable budgets/generators and all four
  latest-head CI jobs pass. Record reproducible owner UI review steps without
  claiming human quality acceptance; U-113 closes only with integrated evidence.
