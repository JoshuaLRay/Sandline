# U-209 — Temporary overhead awareness indicators (○ ? … ! !!)

Epic: Stealth and enemy awareness ([U-204](U-204.md)). Pillar: P4.
Size: M. Human verdict: batched in U-212 (readability on desktop and phone).
Status, priority, dependencies and branch/PR live in [BACKLOG.md](../../BACKLOG.md).
Source: owner, 2026-10-16 — "Before implementing audio cues for enemy awareness, add temporary visual indicators above enemy characters' heads … These indicators are temporary development/training UI … Separate the underlying AI work from the overhead-indicator implementation so each can be tested independently." Design §6.

## Problem / outcome

Players and developers cannot see what an enemy knows. Outcome: each enemy
shows its authoritative awareness state above its head — Unaware ○,
Suspicious ?, Investigating …, Alerted !, Combat !! (preliminary glyphs; final
choice recorded in the card) — updated on the same snapshot as the state,
never visible through walls, readable on desktop and in the mobile spectator
view, and switchable off.

## Scope

- Wire: 3 bits for the awareness state on the Enemy component (protocol bump);
  the host writes U-205's state.
- Client: one module (e.g. `client/src/ui/AwarenessMarkers.ts`) drawing a
  screen-sized label at the enemy's head, only while that enemy's body is drawn
  and its head point is visible from the camera (depth/line-of-sight test
  against the world); hidden for corpses, the tank and the POW (proposal).
- Glyphs: system-font characters where available, drawn shapes as fallback
  (the ellipsis and "!!" may need a shape); high contrast with an outline.
- Settings: "Show enemy awareness" (default on while the feature is new); a
  room/host override for playtests; mobile spectator honours the same setting.
- Removal path documented: delete the module, the setting and the wire field.

## Acceptance criteria

- [ ] Every client shows the same state for the same enemy, changing on the snapshot that carries the change.
- [ ] No indicator for an enemy behind a wall, outside relevance, or off screen; none on the compass.
- [ ] Legible at phone size in the mobile spectator view and at 1080p; glyph fallback tested.
- [ ] The setting hides all indicators without affecting AI; AI tests pass with the module removed (independence).
- [ ] Protocol bumped and pins updated.
