# U-104 — Hold Tab to access the mouse

Epic: **Controls / UI**. Status, priority, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).
Source: owner request, 2026-10-04: “holding tab should access my mouse for as long as I’m holding it”.

## Problem / outcome

Tab currently displays the scoreboard without releasing pointer lock. Hold Tab to use the cursor; release it to resume mouse look. Build, browser and mode: UNKNOWN.

## Scope

Client input and scoreboard lifecycle only. Preserve fullscreen and scoreboard behavior. Resume only a lock released by this hold, while gameplay is active; cancel on Escape, F11 or loss of focus. Keep the cursor free while clicking the canvas during the hold.

## Start here

`packages/client/src/input/LocalInput.ts`, its tests, and `packages/client/src/main.ts`.

## Acceptance criteria

- [x] Holding Tab releases the pointer and keeps the scoreboard visible; canvas clicks do not capture it.
- [x] Releasing Tab resumes a previously captured pointer during active gameplay, including a quick tap.
- [x] Repeats, text fields, an initially free cursor, blur, Escape/F11, menus and mission completion do not cause unwanted capture.
