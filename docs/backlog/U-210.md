Do not create isolated equipment rules that would later need to be rewritten." Parity CP-19 (series: suppressed weapons on sentries; Global Storm: suppressed pistols).

## Problem / outcome

No suppressed weapon exists. Outcome: a suppressor reduces a weapon's noise
radius (U-206) and stops a shot locating the shooter beyond close range, with
a small ballistic cost, and it is an item the loot system can drop.

## Scope

- Preferred: a suppressor **attachment** (U-191) modifying `noiseM`.
- Interim, only if the owner wants stealth before attachments: suppressed
  variants as weapon rows using the same `noiseM` field, migrated to base +
  attachment by U-191 (the migration is part of U-191's scope).

## Decision needed

**Should suppressors wait for the attachment system?**
A — wait for attachments (U-191): one clean model, but no suppressed weapon
until the loot work reaches attachments;
B — ship one or two suppressed weapon variants now (e.g. a suppressed SMG and
pistol) and convert them to attachments later (stealth play sooner; a small
migration later);
C — no suppressors.
**Recommended default: B**, because stealth (U-204) needs a quiet weapon to be
playable, and the variants use the same noise field the attachment will
modify, so the later conversion is mechanical. Reply "agree" or pick another.
