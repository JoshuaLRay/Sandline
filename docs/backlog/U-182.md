# U-182 — C4: right click sets off the oldest charge, R sets off all

Epic: Weapons and equipment (owner direction 2026-10-16). Pillar: P4.
Size: M. Human verdict: none (engineering criteria; the feel is judged in the next batched mission playtest, U-119).
Status, priority, dependencies and branch/PR live in [BACKLOG.md](../../BACKLOG.md).
Source: owner, 2026-10-16 — "Existing mouse-click detonation action: detonates the earliest-placed active C4 charge … individually, in placement order (FIFO) … R key: detonates all currently active C4 charges controlled by the player." Explicitly approved for implementation now. Decision record: [ADR-026](../adr/026-c4-detonation-controls.md).

## Problem / outcome

Right click with C4 in hand set off every charge the soldier had out (U-054,
D-11). Outcome: right click sets off only the oldest armed charge (one per
press, placement order); R sets off all of them at once; R with a gun in hand
is still reload. Server-authoritative, owner-only, deterministic order.

## Scope

- Server: split the detonator into `detonateOldestCharge` and
  `detonateAllCharges` over `chargesOut` (the soldier's own armed charges of the
  kind in hand, sorted by net id = placement order). Press-edge detection for
  both buttons; R wins a tick both are pressed on.
- Wire: new input button `detonateAll` (bit 8 of the existing 16-bit field);
  `PROTOCOL_VERSION` 73 → 74.
- Client: R is sampled as `detonateAll` and kept only with placed charges in
  hand; the reload handler is unchanged for guns. Key list and a hint on
  drawing charges name both detonators.
- Bots: the armour attack keeps "all at once" (it waits until the squad is
  clear); the single-charge detonator is ready for the plant/detonate order
  (U-198).
- Claymores share the path: manual detonation follows the same two rules.

Out of scope: remappable keys (the settings menu is display-only today),
mission charge points with fuses (Mission 2 N1), bot orders to plant.

## Acceptance criteria

- [x] Right click sets off the earliest-placed armed charge only; each further click the next oldest; none out → nothing.
- [x] Holding right click does not set off more than one.
- [x] R sets off every armed charge of the kind in hand at once; charges are consumed, not refunded; blast damage and friendly fire as before.
- [x] Right click and R on the same tick: everything goes once.
- [x] R with a gun in hand sets off nothing (and stays reload on the page).
- [x] Only the presser's own soldier's charges; another player's right click or R reaches none of them; a downed owner cannot detonate.
- [x] A charge taken back (E), expired or already detonated is skipped; the next press reaches the next one.
- [x] Placement order survives a checkpoint retry.
- [x] Key list and draw hint name both detonators.
