# U-132 — Finite cache data and capacity-safe supply transfers

Epic: Map implementation. Status, dependencies and work live in [BACKLOG.md](../../BACKLOG.md).
Source: implementation leaf of [U-112](U-112.md), Mission 1 specification §12/§14.

## Scope

Add strict, optional static cache declarations to mission scripts, with persistent
unique IDs, exact 3D feet and finite projectile, health-kit and primary-magazine
stock. Keep these separate from weapon pickups and preserve legacy scripts.
Implement pure transfer rules using existing class capacities and the actual
held primary's magazine. Preserve equipment/weapon identity and unclaimed stock;
health charges replenish kits rather than health. Represent partial magazine
equivalents exactly so mixed weapon sizes cannot accumulate or duplicate stock.

Runtime timing, physical placement/reach/LOS, serialized completion, wire state
and save/retry lifecycle belong to U-133. Choice/progress/scenery UI belongs to
U-134. The five production caches are placed with exact counts in U-117.

## Acceptance and verification

- Unknown fields, duplicate/malformed IDs, nonfinite/out-of-range feet,
  unknown/non-carried projectile IDs and invalid stock fail shared validation;
  legacy scripts remain valid. A five-cache fixture retains all §12 contents.
- Transfers fill only compatible free capacity, move one chosen type, and
  retain unclaimed stock. Empty/full/incompatible attempts change nothing.
  Primary-ammo transfers charge only the exact delivered magazine fraction,
  preserve whole rounds, and never refill a pistol, melee weapon or stowed gun.
- Focused shared regressions, `pnpm verify`, applicable budgets/generators
  and all four latest-head CI jobs pass; actual evidence is recorded.

Implemented strict, optional top-level `supplyCaches` on event scripts. IDs/feet
and all stock fields are validated; omitted stock defaults to zero, omitted
caches preserve legacy script shape. Static declarations stay separate from
weapon pickup actions and IDs. The five-cache §12 fixture retains 24 rockets,
21 magazine equivalents, eight kit charges and every specified floor/position.

Pure `transferSupply` fills only compatible free projectile capacity, restores
one kit charge, or fills the actual held primary's magazine (including a held
second primary). It preserves weapon/equipment identity and other inventory.
Full, empty and incompatible attempts return unchanged inputs. Stock retains
all unclaimed supplies. One magazine equivalent uses 2,400 integer storage
units; whole-round refills across SMG/rifle/LMG sizes conserve exact stock,
including sub-round remnants through validated JSON stock round-trips.
