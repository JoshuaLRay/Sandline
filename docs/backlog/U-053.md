# U-053 — Bots use health kits on downed or hurt mates

Epic: **Controls**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: split from [U-047](U-047.md) (its last criterion).

## Problem / outcome

Human soldiers apply health kits (U-047); bots carry them (`slot.kits`) but never use them. A bot should be able to apply a kit to a downed mate (and, as a proposal, to a hurt one) under the same rules as a human: the same time, reach, cancels and spend.

## Scope

A bot behaviour, not a change to the item: when a mate is downed and the bot has kits, the brain draws the kit and holds the use for `kit.seconds`, cancelling on the same conditions. Open question: bots already revive with the 3 s hold-E route, which is faster; propose using a kit only when a revive is not possible (the target is hurt, not downed) or as an owner-chosen preference. The bot brain blackboard (`packages/server/src/ai/friendly/orders.ts`) and `Session.updateKits` (which skips autonomous slots today) are the places to start.

## Acceptance criteria

- [x] A bot with kits applies one to a hurt mate in reach under the human rules (same time, reach, cancels and spend). A downed mate is still revived by hold-E, which is faster (the card's proposal, taken).
- [x] It does not waste a kit on a full-health mate and never on itself while downed.
- [x] Covered by a server test with a bot slot.

## Handoff / evidence

Implemented on `task/U-053-bot-kits`; awaiting review. No owner verdict is claimed.

**What changed.** The friendly tree gains `hurtMate` and `heal` after the revive branch (`data/trees/friendly.json`, `actions/friendly.ts`): a bot that still has kits, is not pinned down, and sees a hurt (alive, not downed) squadmate below `squad.json` `bot.kitBelowFraction` (0.5) of their health within `reviveSeekM`, that no other bot is already healing, walks to them and holds `useKit` beside them. The session clears `useKit` before each think and, while it is true, draws the kit for the bot and runs it through the human's `updateKits` (10 s, cancelled by damage, reach or a pre-empting branch; spent on completion).

**Evidence.** `packages/server/src/ai/friendly/heal.test.ts`: a bot walks to a mate at 20 HP, heals them to full in about the kit time plus a walk and spends one kit; a mate at 80 HP is left alone and a bot with no kits stays put; a downed mate is revived and no kit is spent.

**Proposal (labelled).** The 50% threshold and "hurt only, revive for the downed" are mine; both are data or one tree branch away from being changed.
