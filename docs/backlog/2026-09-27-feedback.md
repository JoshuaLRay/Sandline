## Character state and mission consequences → U-029–U-032

Downed and dead characters should not be able to rotate. They can rotate the
camera, but not the character. Downed characters should not be targeted by enemy
fire at all. The owner would like a prisoner-of-war system: an enemy can capture
a downed player, who then has to be rescued in the next mission. A character's
death ends the mission and returns play to the last checkpoint.

The camera/body distinction, eligible set of characters for the mission-failure
rule, enemy capture/interruption behavior, and campaign persistence/rescue
details have not been specified. See the linked cards for proposed scope and
acceptance criteria; no implementation or reproduction is claimed.
