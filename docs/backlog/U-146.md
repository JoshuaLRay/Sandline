compatible item, with monotonic request IDs and explicit cancellation. Preserve
desktop held-E use. The host validates existing autonomous command authority and

progress replication, contention and checkpoint semantics.

remain U-147 and U-148. No temporary possession or manual mobile soldier controls.

## Implementation and evidence — 2026-10-08

Protocol 69 adds reliable `CommanderSupplySelect` with a separate increasing
32-bit request ID, recipient slot 0–5, validated cache ID and one supply item
or null cancellation. The host keeps the issuer separate from the recipient;
existing autonomous ownership and class/fireteam reach are checked on acceptance
and every tick. The issuer's own spectator-driven seat is eligible, while an
active human or merely watched soldier grants no command authority.

Accepted nearby collection replaces the ordinary order, suspends bot movement,
fire and competing interactions, and transfers once after 30 ticks (Support:
24). It uses current finite stock/inventory, floor-aware 3D reach and LOS. No
commander E, possession transfer, distant-cache travel or mobile UI is added.
Ordinary replacement, cancellation and all ownership/mission/save lifecycle
changes clear unfinished uses. Legacy saves without cache data also clear
transient selections without replenishing spent stock.
