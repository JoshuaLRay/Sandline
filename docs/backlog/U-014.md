# U-014 — Play intelligible radio-treated squad dialogue

Epic: **Audio**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: [owner feedback, 2026-09-26](2026-09-26-feedback.md), plus any legacy bug named below.

## Problem / outcome

The owner wants dialogue that sounds as though it comes through a radio, rather than only the current fallback chirp.

## Scope

Wire the real squad callouts through the existing processed radio variants and communication channel; use filtering, controlled distortion and radio clicks as appropriate without obscuring the words.

## Acceptance criteria

- [ ] Relevant squad dialogue plays a real, intelligible line with radio treatment; the chirp is only a labelled missing-content fallback.
- [ ] Concurrent callouts are prioritized/limited rather than stacking without bound.
- [ ] Local bodily sounds remain local/positional; radio dialogue is not incorrectly attenuated into silence by distance.
- [ ] Death/retry/reconnect clears stale dialogue, and sound-board samples expose dry/radio comparisons.

## Verification
