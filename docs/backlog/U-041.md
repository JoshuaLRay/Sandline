# U-041 — Carry the roster weapons on the wire

Epic: **Squad**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: split from [U-020](U-020.md) on 2026-09-29 (that card required splitting before READY: more than one substantial new weapon behavior, plus art, audio and wire changes).

## Problem / outcome

`WEAPON_IDS` (the wire order) has five entries and the Weapon/Pickup component fields are 2-3 bits wide, so no soldier or pickup can carry the LMG or the U-040 weapons. Nobody can be equipped with the roster's guns until they can be named on the wire.

## Scope

Append the roster weapons to `WEAPON_IDS`, widen the affected fields (`Weapon.index`, `Weapon.primary`, `Pickup.weapon`, the `Fire`/`Possessed` weapon fields), bump `PROTOCOL_VERSION`, and update the pickup and class validators. Append only, never renumber (ADR-009). Netcode change: needs headless integration coverage.

## Start here

`packages/shared/src/sim/weapons.ts` (`WEAPON_IDS`), `packages/shared/src/net/schema.ts`, `packages/shared/src/net/protocol.ts`, `packages/shared/src/sim/pickups.ts`, `packages/shared/src/sim/classes.ts`.

## Acceptance criteria

- [x] Each roster weapon round-trips through the schema, the `Fire` message and a pickup.
- [x] Existing indices are unchanged and old data still decodes as before; the protocol version is bumped with the reason recorded.
- [x] Hosted-session integration test: a soldier holding each new weapon replicates to a client, and a dropped one becomes a pickup.

## Verification

Schema/protocol unit tests, the netcode integration suite and `pnpm verify`.

## Handoff / evidence

Branch `task/U-041-weapon-wire`.
- `WEAPON_IDS` gains, at the end, `lmg`, `smg`, `carbine-scoped`, `sniper-semi`, `sniper-bolt-left` (indices 5-9; 0-4 unchanged). New `WEAPON_INDEX_BITS = 4` (sixteen ids) sizes `Weapon.index`, `Weapon.primary`, `Pickup.weapon` (`PICKUP_WEAPON_BITS` 3 to 4) and the `Fire` message's weapon field (3 to 4 bits). **`PROTOCOL_VERSION` 44 to 45**, because widths changed.
- Side effect fixed: `Weapon.index` was 2 bits, so the knife (index 4) clamped to 3 on the wire and remote soldiers holding a knife replicated as holding the sidearm. It is now exact (test included).
- Equip item codes follow `WEAPON_IDS.length` (guns first, then the pouch), so pouch items are now items 10 and 11; both ends derive them from the same array, `RELOAD_ITEM` stays 15.
- Client: code-built models for the four new ids (they borrow the marksman/carbine silhouettes until U-042); muzzles and sounds were mapped in U-040. The free-range QA keys 7-9 now reach marksman, breacher and the LMG.
- Tests: fixed the tests that asserted the old count (`lmg` off the wire, protocol 44, a "bad" weapon index 7); new tests in `Session.test.ts`: each roster weapon replicates as the gun in hand and as the primary, the knife replicates as the knife, dropped roster guns become pickups with their ammo, and `Fire` round-trips every id (all fail with 2-bit fields).
- Not changed: the pickup drop table (`pickups.json` still drops only the carbine, marksman and breacher), classes (nobody is issued these guns yet: U-021/U-029).
- `pnpm verify` and CI on the PR.
