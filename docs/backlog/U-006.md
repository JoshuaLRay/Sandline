# U-006 — Keep the gun visible during a readable reload animation

Epic: **Weapon feel**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).

## Problem / outcome

Reloading currently appears to make the gun disappear. The owner wants an actual animation.

## Scope

Animate the AR reload with the existing procedural approach: lower/tilt, magazine handling and return to ready. Match the weapon reload clock. Do not change reload balance as part of the presentation fix.

## Acceptance criteria

- [ ] The gun stays visible in FPS through reload; hands/magazine movement makes the action readable.
- [ ] Standing/crouched/prone and ADS-to-reload transitions do not hide or pop the weapon; TPS and remote reloads remain coherent.
- [ ] Weapon swap, down/death, interruption and checkpoint retry clear/reset presentation correctly.
- [ ] Ammo becomes available only on authoritative reload completion, and existing stage audio can synchronize with the animation.
