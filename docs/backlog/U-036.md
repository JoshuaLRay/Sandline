# U-036 — Collect friend voice recordings and consent in the game

Epic: **Audio**. Status and priority live only in [BACKLOG.md](../../BACKLOG.md).
Source: owner direction, 2026-09-28: send friends to the game to record and submit their voices after clicking their consent.

## Problem / outcome

The repo's voice processor expects consented recordings under `assets/voice/raw/`, but asking friends to name files and upload them to GitHub is too cumbersome. A friend should be able to open the game, read the script, record and hear a take, consent, and send it to the owner without access to the repository.

## Scope

Add a browser recording page and an invite-only HTTP intake on a persistent host volume. Accept recordings by script section; consent text and server timestamp stay beside them. The owner reviews and explicitly imports a finished submission into the existing offline pipeline. No submitted clip automatically reaches players. The invite key and intake directory are operator configuration, not committed assets. Updates to on-demand generated voices and live chat are outside this task.

## Acceptance criteria

- [ ] A friend can open the voice page from the game's lobby, accept the exact terms, record/listen/re-record, upload at least one section, and finish.
- [ ] The API refuses missing or incorrect consent, invitation, submission token, unscripted sections, unsupported formats, excess sizes, and an untrusted browser origin; it does not publicly serve source audio.
- [ ] Each submission retains name, consent text, time, section files and completion state on private persistent storage. An owner can import only a completed submission, then review and run `gen:voice`.
- [ ] The deployed site's host can enable intake through documented environment settings. With settings absent, gameplay hosting still works.

## Verification

API tests for consent/auth/limits and a manual browser microphone and audio review. `pnpm verify`; test a complete submission on a configured host before saying the live path works. The owner's listening verdict is separate from code checks.
