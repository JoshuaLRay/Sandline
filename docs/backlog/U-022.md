# U-022 — Implement the faster dual-primary support role

Epic: **Squad**. Status, priority and dependencies live only in [BACKLOG.md](../../BACKLOG.md).
Source: [owner feedback, 2026-09-26](2026-09-26-feedback.md), plus any legacy bug named below.

## Problem / outcome

The support character carries both SMG and shotgun, runs a bit faster, and cannot ADS or enter FPS.

## Scope

Implement the approved support inventory/control rules and data-driven speed bonus. Enforce constraints in authoritative state and local prediction. Preserve 2=pistol where the approved support policy includes a pistol; use the approved mapping for selecting either primary.

## Acceptance criteria

- [ ] Support can carry and switch between both SMG and shotgun with independent ammo/reload state.
- [ ] ADS and FPS are unavailable via all paths, including saved view preference, recoil/scope toggles, respawn, reconnect and possession change.
- [ ] The speed bonus uses the approved configured value, agrees on client/server and does not apply to other characters.
- [ ] Enemy-weapon pickup replaces only the intended active primary; the other primary and pistol policy remain correct.
