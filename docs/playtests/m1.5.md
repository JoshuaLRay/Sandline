## What this establishes

Everything the LAN gate established, now across the internet with no
conditioning: the latency was whatever the route between two real networks
and a host in Virginia gave, which is the entire point of the task. Two
humans shot each other over a real WebSocket through a real TLS edge, having
joined through the lobby with a room code and nothing else. NAT traversal and
connection establishment against a remote host, which `m1.md` and
`m1.5-lan.md` both list as unproven, are proven by the session having
happened at all.

This is the answer to R2 that M1 could not give: an authoritative-server
third-person shooter, predicted and reconciled in a browser, felt good to the
person judging it with another person shooting back across a real link.

## What it does not establish

**No measured numbers.** T-1.5.08's done-when is "a written verdict at real
internet latency with measured numbers beside it", so that the verdict can
be read against the NetSim cells T-1.22 asserts in CI, and so that where they
disagree the model can be revisited. The netgraph over a remote host shows
`rtt`, `jitter` (measured), the correction rate, peak divergence, snapshots
applied, missed baselines and in-flight inputs. **None of these was written
down.** The verdict therefore cannot be placed against the harness's LAN /
Good (40 ms, 5 ms jitter) / Poor (80, 15, 5% loss) / Awful (200, 40, 20%)
presets, and it says nothing about whether NetSim's uniform jitter model
resembles the real route. That comparison is still owed, and it is cheap:
the next two-person session should read the three netgraph lines aloud
once each and paste them here.

**The individual cases are not individually recorded**, exactly as in
`m1.5-lan.md`: doorway contest, trades inside the rewind window, "I shot
first" disputes, corpse damage. Same remedy.

**One route, one pair, one evening.** Two networks and one host region. Not
a mobile link, not a transatlantic route, not a congested evening, not
packet loss worth the name. The T-1.5.07 host is a single small machine that
stops when idle; nothing about capacity, a third player joining mid-session,
or the host surviving both players leaving and returning is recorded, though
T-1.5.07's own acceptance names those and the room registry's tests cover
the mechanics (T-1.5.05).

**"Looks great" is a report of feel, not a measurement.** That is what a
human gate is for, and it is enough to open M2. It is not enough to tune
against, which is why the numbers above are still owed.
